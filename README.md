# 🏥 신규 개원 찾기

건강보험심사평가원 공공데이터로 **최근 새로 문 연 병원·의원**을 지역별로 찾아 주는 웹앱입니다.

- 지역(시·도), 기간(1·3·6·12개월), 기관 종류(의원·병원·요양병원 등) 선택
- 개설일자 최신순 목록, 시·군·구별 묶어 보기, 이름·주소 검색
- 전화 걸기, 카카오맵, 네이버 검색 바로가기
- 엑셀(CSV) 저장

## 동작 방식

```
브라우저(index.html) → /api/new (Vercel 함수, 인증키 보관) → 심평원 병원정보서비스 API
```

심평원 API에는 "개설일자로 검색" 조건이 없어서, 서버가 선택한 시·도·종류의 기관 목록을 페이지별로 모두 받은 뒤
개설일자(`estbDd`)가 기준일 이후인 곳만 골라 돌려줍니다. 같은 조건의 결과는 Vercel에서 6시간 캐시해
심평원 호출량(개발계정 하루 10,000건)을 아낍니다.

## 1. 공공데이터 인증키 발급

1. [공공데이터포털](https://www.data.go.kr) 회원가입 후 로그인
2. [건강보험심사평가원_병원정보서비스](https://www.data.go.kr/data/15001698/openapi.do) 페이지에서 **활용신청**
   (활용목적 예: "제약 영업 신규 거래처 확인용 웹 서비스 개발") → 개발계정은 자동 승인
3. 마이페이지 → 데이터활용 → Open API → 활용신청 현황에서 **일반 인증키(Decoding)** 복사
   - 승인 직후에는 키가 동작하기까지 1~2시간 걸릴 수 있습니다.

## 2. Vercel에 배포

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인
2. **Add New → Project** → 이 저장소 선택 → **Import**
3. **Environment Variables**에 추가
   - Name: `HIRA_KEY`
   - Value: 위에서 복사한 인증키
4. **Deploy** → 발급된 주소(`https://○○○.vercel.app`)로 접속

키를 나중에 넣었다면 Settings → Environment Variables에 추가한 뒤 Deployments에서 **Redeploy** 해야 반영됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (한 파일) |
| `api/new.js` | Vercel 서버 함수 — 인증키를 숨기고 심평원 API 중계 |
| `lib/hira.js` | 심평원 호출, 페이지 순회, 개설일자 필터 |
| `test/run.mjs` | 가짜 데이터로 하는 동작 검사 (`npm test`) |

## 참고

- 출처 표시: 건강보험심사평가원 병원정보서비스(공공데이터포털, 공공누리 제1유형)
- 심평원 등록 기준이라 실제 개원일과 차이가 날 수 있습니다.
- 대구 의원 전체처럼 범위가 넓으면 첫 조회에 20~30초 걸릴 수 있습니다. 이후 6시간은 캐시로 바로 뜹니다.
